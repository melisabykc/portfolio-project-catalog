# Portfolio Project Catalog

A small Python CLI for keeping a catalog of portfolio projects.

## Tarayıcı arayüzünü çalıştırma

Python 3.10 veya üzeri kurulu olmalıdır.

```bash
pip install -r requirements.txt
streamlit run app.py
```

Komut çalıştıktan sonra terminalde gösterilen yerel bağlantıyı tarayıcıda aç.

## İnternette yayınlama

Depoyu [Streamlit Community Cloud](https://share.streamlit.io/) üzerinden seç, ana dosya olarak `app.py` belirt ve **Deploy** düğmesine bas. Yayınlama tamamlanınca uygulamaya özel bir web bağlantısı oluşturulur.
